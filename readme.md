# survey

Статическая библиотека на C++20 для интерактивных опросов в консоли. Вопросы с выбором
управляются стрелками и цветом, есть ввод текста и пароля. Работает на Windows и Linux.

```text
Как ваше настроение?
1. Хорошо          ← цвет курсора
2. Нормально       ← цвет отмеченного
3. Плохо
```

После ответа список сворачивается:

```text
Как ваше настроение?
- Нормально
```

### Подключение

```cmake
include(FetchContent)
FetchContent_Declare(
	survey
	GIT_REPOSITORY https://github.com/lconantl/survey.git
	GIT_TAG v1.0.0)
FetchContent_MakeAvailable(survey)

target_link_libraries(app PRIVATE survey::survey)
```

### Управление

| Клавиша      | Один вариант                                               |
|--------------|------------------------------------------------------------|
| ↑ / ↓        | Курсор, по кругу                                           |
| 1–9          | Перейти и отметить                                         |
| Пробел       | Отметить (повторно — снять)                                |
| Enter        | Подтвердить отмеченное, без отметки — вариант по умолчанию |
| Esc / Ctrl+C | `survey::CancelledError`                                   |

Вариант по умолчанию — первый, если не указан явно через `Default()`. Курсор стартует на нём.
Если курсор стоит на отмеченном пункте, побеждает цвет курсора.
